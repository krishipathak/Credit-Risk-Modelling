# Credit Risk Modeling

A credit risk modeling project covering **Probability of Default (PD), Loss Given Default (LGD), Exposure at Default (EAD), and Expected Loss** using Python.

## Project Overview

- Data preparation and preprocessing
- Feature selection using Weight of Evidence (WoE) and Information Value (IV)
- PD modeling using Logistic Regression
- LGD modeling using a two-stage approach
- EAD modeling using Credit Conversion Factor (CCF)
- Expected Loss calculation

## Tools & Techniques

**Python | Pandas | NumPy | Scikit-learn | Matplotlib | Logistic Regression | WoE | IV**

## Project Structure

- Credit_Risk_Modeling_Preparation.ipynb – Data preparation and preprocessing
- Credit_Risk_Modeling_PD_Model.ipynb – Probability of Default model
- Credit_Risk_Modeling_LGD_EAD_Expected_Loss.ipynb – LGD, EAD and Expected Loss

## Key Outcome

Built an end-to-end credit risk framework linking **PD, LGD and EAD** to estimate expected credit losses.
